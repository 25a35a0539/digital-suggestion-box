# Digital Suggestion Box

## 📌 Project Description
Digital Suggestion Box is a simple frontend web project where users can submit their suggestions online.  
It replaces the traditional physical suggestion box with a digital version.

This project is built using:
- HTML
- CSS
- JavaScript

---

## 🎯 Features
- Welcome Page
- Suggestion submission form
- Animated suggestion box image
- Paper drop animation when submitting
- Basic form validation
- Success message after submission

---

## 💻 How to Run the Project

1. Download or copy the project files.
2. Save the file as `index.html`.
3. Open the file in any web browser (Chrome, Edge, Firefox).
4. Click on **Give Suggestion**.
5. Enter your suggestion and click **Submit**.

---

## 🛠 Technologies Used
- HTML for structure
- CSS for styling and animations
- JavaScript for interaction and form validation
